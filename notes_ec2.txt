Store the github secrets for yml 

1. Go to your GitHub Repository page
2. Click on the ⚙️ Settings tab at the top.
3. In the left sidebar, scroll down to the Security section and click on Secrets and variables -> Actions.
4. Click the green New repository secret button at the top right.
5. Create three separate secrets with the exact names and values below:


EC2_HOST	The public IPv4 address or Public DNS domain of your EC2 instance.
EC2_USER	The default SSH username for your server instance (e.g., ubuntu for Ubuntu, ec2-user for Amazon Linux).
EC2_SSH_KEY	The entire text content of your private key (.pem file). Make sure to include the -----BEGIN RSA PRIVATE KEY----- and -----END RSA PRIVATE KEY----- wrapper lines.

3. Deploy using Docker Compose
From your project root:

docker compose \
  -f docker-compose.yml \
  -f docker-compose.prod.yml \
  config



This validates and renders the merged Compose configuration. Be careful: rendered output can contain secrets, so don't share or publish it.
Then build and start:
docker compose \
  -f docker-compose.yml \
  -f docker-compose.prod.yml \
  up -d --build



Verify the containers:

docker compose \
  -f docker-compose.yml \
  -f docker-compose.prod.yml \
  ps


.github/
└── workflows/
    └── deploy.yml



name: Deploy Microservices to EC2

on:
  push:
    branches:
      - main
  workflow_dispatch:

permissions:
  contents: read

concurrency:
  group: production-deployment
  cancel-in-progress: false

jobs:
  deploy:
    name: Deploy to Production
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      # Add automated test steps here before deployment.

      - name: Deploy on EC2
        uses: appleboy/ssh-action@v1.2.0
        with:
          host: ${{ secrets.EC2_HOST }}
          username: ${{ secrets.EC2_USER }}
          key: ${{ secrets.EC2_SSH_KEY }}
          script_stop: true
          script: |
            set -eu

            cd /opt/microservices

            echo "Pulling latest code..."
            git pull --ff-only origin main

            echo "Validating production Compose configuration..."
            docker compose \
              -f docker-compose.yml \
              -f docker-compose.prod.yml \
              config --quiet

            echo "Building production images..."
            docker compose \
              -f docker-compose.yml \
              -f docker-compose.prod.yml \
              build

            echo "Deploying services..."
            docker compose \
              -f docker-compose.yml \
              -f docker-compose.prod.yml \
              up -d --remove-orphans

            echo "Checking container status..."
            docker compose \
              -f docker-compose.yml \
              -f docker-compose.prod.yml \
              ps

            echo "Deployment commands completed."
